## Summary
CAN bus (Controller Area Network) is a vehicle bus standard designed to allow microcontrollers and devices to communicate with each other. It is a message-based protocol originally developed for multiplex electrical wiring within automobiles to reduce copper usage, though it is now used in many other contexts as well (CAN bus - Wikipedia).

The purpose of CAN bus is to enable efficient communication between multiple electronic devices or nodes in a distributed system. It has become the leading standard for in-vehicle networking and is widely used in industrial and embedded applications. For beginners looking to understand its practical application, CAN bus tutorials cover the CAN frame structure, higher-layer protocols, and how to log and decode CAN bus data (CAN Bus Explained - A Simple Intro [2026] - CSS Electronics).

In terms of basic operation, CAN uses a multi-master architecture, meaning any node can initiate communication when the bus is idle. This differs from master-slave protocols such as SPI or I2C. The peer-to-peer approach, combined with non-destructive arbitration, makes CAN highly efficient for distributed systems (The Complete CAN Bus Technical Guide - nimbustan.github.io).
